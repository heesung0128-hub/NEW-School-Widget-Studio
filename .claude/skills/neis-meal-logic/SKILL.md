# NEIS 급식 로직

[src/utils/neisApi.ts](../../../src/utils/neisApi.ts)가 나이스 오픈 API 연동을 전담한다. 여기 로직을 고칠 때는 아래 4가지 규칙이 서로 얽혀 있다는 걸 알고 있어야 한다.

## 1. 급식 전환 시간 (오늘 급식 ↔ 내일 급식)

[`getMealTargetDate()`, lines 52-78](../../../src/utils/neisApi.ts): 설정 가능한 `switchTime`(기본 `'13:30'`) 기준으로, 현재 시각이 그 시각을 지났으면 조회 대상 날짜를 **내일**로 넘긴다. 점심을 이미 먹었을 시간에는 위젯이 다음 급식(내일 점심)을 미리 보여주기 위한 의도적 설계다.

- 파싱 실패 시(`switchTime`이 이상한 값이면) `13:30`으로 폴백 (`isNaN(switchHour) ? 13 : switchHour` 등)
- 이 전환 이후 대상 날짜가 **토요일**이면 +2일(월요일로), **일요일**이면 +1일(월요일로) 추가 이동 — 주말에 급식이 없다는 걸 감안한 처리

→ `mealSwitchTime` 관련 설정 필드를 건드릴 때는 이 파싱 폴백과 주말 스킵 로직이 여전히 맞물려 동작하는지 확인한다.

## 2. 점심 행(row) 선택

[`fetchNeisMeal()`, line 152](../../../src/utils/neisApi.ts): NEIS API가 하루에 여러 급식(조식/중식/석식)을 반환할 수 있는데, `MMEAL_SC_CODE === '2'`(중식)인 행을 우선 찾고, 없으면 첫 번째 행을 쓴다. 다른 끼니(예: 석식)를 지원하도록 확장하려면 이 하드코딩된 `'2'`부터 손봐야 한다.

## 3. 알러지 표기 정리

[`cleanMenuText()`, lines 32-49](../../../src/utils/neisApi.ts): NEIS가 내려주는 원본 메뉴 텍스트(`<br/>` 구분, `"현미밥 (1.5.6)"` 같은 알러지 번호 포함)를 처리한다.
- `<br/>` 또는 `<br>`를 줄바꿈으로 변환 후 줄 단위로 분리
- `removeAllergies`가 true면 `\([0-9\.\s]+\)` 정규식으로 괄호 안 숫자(알러지 코드)를 제거하고, `[0-9\.]+\s*$` 정규식으로 끝에 남는 단독 숫자도 제거

→ 알러지 표시 토글(`showAllergies`) 관련 UI를 고칠 때, 이 두 정규식이 실제 NEIS 응답 형식(괄호 안 숫자, 끝자리 숫자)을 전제하고 있다는 걸 알아야 한다. NEIS가 형식을 바꾸면 여기가 먼저 깨진다.

## 4. 네트워크/CORS 실패 시 "절대 빈 화면 금지" 원칙

`searchSchools()`([lines 96-129](../../../src/utils/neisApi.ts))와 `fetchNeisMeal()`([lines 179-209](../../../src/utils/neisApi.ts)) 둘 다 `fetch` 실패(네트워크 오류, CORS 등)를 `catch`해서 **항상 그럴듯한 폴백 데이터를 반환**한다 — 빈 배열이나 에러 상태를 그대로 던지지 않는다.

- `fetchNeisMeal`의 폴백은 `isNextDay` 여부에 따라 다른 샘플 메뉴를 보여주고, `showAllergies`에 따라 알러지 숫자도 동일하게 제거해준다 — 즉 정상 응답 경로와 **동일한 사용자 경험**을 흉내낸다
- "급식 정보 없음"(방학/휴일/미등록, [lines 168-178](../../../src/utils/neisApi.ts))과 "네트워크 실패"([lines 179-209](../../../src/utils/neisApi.ts))는 서로 다른 분기이며 메시지도 다르다 — 둘을 섞지 말 것

→ 이 폴백 데이터는 브라우저 시뮬레이터가 CORS 때문에 나이스 API를 직접 못 부르는 상황에서도 위젯이 "빈 카드"로 보이지 않게 하려는 의도다. 급식 관련 로직을 고칠 때 이 폴백 경로를 실수로 지우거나 우회하지 않도록 주의한다 (예: `try/catch` 없이 직접 `await fetch`를 호출하는 코드로 바꾸면 이 안전장치가 사라진다).
